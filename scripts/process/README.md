# Processamento

Esta pasta reúne ferramentas de processamento usadas neste fork NEMPA. Ela não é
um espelho fiel da organização upstream de `jwohlwend/boltz`; confira a
procedência de cada arquivo antes de tratá-lo como código original do Boltz.

`filter_manifest_to_existing_structures.py` foi adicionado pela equipe NEMPA.
Ele cria um manifesto lateral com os registros que têm NPZ correspondente e
preserva o manifesto de origem.

Para instruções gerais de processamento, consulte
[a documentação de treinamento](../../docs/training.md).
